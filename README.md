# FAST TRACK (Full-Stack Project)

Note: Make sure you have [Node.js](https://nodejs.org/) v14+ installed.

---

## Client Setup

```bash
cd client
npm install
npm start
```

The frontend will run on http://localhost:3000

## Server Setup

```bash
cd server
npm install
npm start
```

The backend will run on http://localhost:4000

---

After everything is set up correctly, you can open your browser and type http://localhost:3000 to see the app.
